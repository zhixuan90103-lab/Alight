# Alight

英文名 **Alight**：鸟落下并停住。不用 Sling、Angry、Shot，避免被看成弹弓破坏游戏的换皮。

配套：[AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

> 玩法尚未实现。本文是已经对齐的规则，供关卡和原型使用。  
> 场地是底座的竖屏一屏（设计空间 390×844）。镜头不跟鸟走。

## 1. 故事

风把一群还不会自己飞的鸟从岭上掀下来。岭上的窝还亮着各自的颜色。玩家每次托起一只，用弹弓送回去。鸟进了自己的窝就睡着，那盏灯暗下来。进了别的窝，鸟站起来跳下，灯不暗。

鸟不是武器。没有袭击对象，倒塌不计分，也不作为过关条件。

颜色用来认出「这是谁的家」，不做成配色题。窝的颜色就是这户的颜色。体型只决定这只鸟有多重、同一下拉力飞多远，不决定它能不能卡在窝上。

## 2. 每一关都成立

- 画面固定。弹弓和窝同时看得见。
- 每一发都从同一把弹弓拉开再松手。方向和力度一起决定。松手后鸟不再挂在绳子上。
- 落点不是下一发的起点。
- 不画这一发的抛物线。
- 刚刚这只鸟的飞行留下残影，用来改下一拉。换一只鸟，残影清掉。
- 操作在下半屏。拉力的提示画在手指上方。
- 打不进可以马上再拉，也可以整关重来。没有生命，没有等待。

体重和体型绑在一起：一样大就一样重。轻鸟同一下拉力飞得更高，重鸟飞得更近。

## 3. 窝

普通窝只留一只鸟。鸟留不留下，看它是不是到了自己的窝，不看身子有没有卡在沿上。

鸟落到自己的窝里，蜷好睡着，灯暗下去，不再下来。鸟落到别的窝里，站一下再跳下去，灯不暗，窝空出来。窝里已经睡着鸟时，后来的鸟碰到它，也会离开，不会挤进去。

掉下去或弹开之后，鸟落到低处，再滚回画面低点的弹弓。弹弓在低处，所以回来是下坡。玩家不用再按一次把鸟召回。这一发不算失败，马上可以再拉。

力度不够时，鸟掉在窝前面；力度大了，鸟飞过窝再落下。两种同样落到低处，再滚回弹弓。

共用窝是少数关卡才出现的特殊窝。它要单独认得出：更深，有多根栖木，空位看得见。它只收这一关指定的那几只，通常是同色的一家。每进一只，空位少一个。满了以后，再来的鸟离开。

不是这一窝的鸟，即使还有空位，也只站一下就跳下去。空位还在。只有该进这个空位的鸟才会睡着。

## 4. 心和评级

每一关一开始就有三颗心，画在画面上。

- 鸟在自己的位子上睡着，心不变。
- 没睡着而回到低处，都扣一颗心。这包括力度不够掉在窝前、飞过窝，以及落到别的窝里再跳下。画面上都是鸟没留下，心少一颗。
- 心里还有剩，鸟滚回弹弓，可以再拉。
- 这一下把最后一颗心扣没，鸟不再回到弹弓，留在地上，也不睡着。之后再没睡着的鸟，同样留在地上。
- 弹弓上没有待发的鸟时，这一关结束。结束时同时看两样：睡着的鸟有几只，心还剩几颗。两样都画在结果上。最高是三只鸟都睡着、三颗心都在。少一只睡着的鸟，或少一颗心，都降一档。
- 整关重来，心和还没发射的安排都恢复。

第一关也会因力度不够扣心。三颗心是整关共用的容错，不是只惩罚认错窝。

## 5. 关卡怎么往下排

同一下拉开不变。每一关改的是窝的位置和鸟的体重，让上一关的拉力不够用。

1. 一个共用窝，三只鸟，只改远近。
2. 仍是一个窝，鸟分成轻和重。
3. 多个单鸟窝，颜色不同。落到自己的窝里睡着，落到别的窝里跳下并扣心。
4. 更好射的那个窝是别人的。跳下去扣心。
5. 共用窝带空位，再加上单鸟窝。只有该睡的那个空位会把鸟留下。跳下错窝扣心。

这一批之后，只换位置会重复。下一章再加一种仍用拉开的局面，例如只挡住高弧的树枝，或整关不变的侧风。有侧风时，同一只鸟的残影仍然有效。

多处起点留到更后，前期不用。窝在一侧，弹弓可以在对面高低不同的崖上，但一只鸟整关只站一个起点，残影才不会指错。每个起点都必须真能把这只鸟送进它该进的窝。第一批关卡仍然全场只有一把弹弓。

窝口的大小留到后面，当作容量，不当作「卡不卡沿」。同一个颜色可以有大窝和小窝。窝里能睡下的身子是看得见的宽度。

小鸟落到大窝里，空还比它大，它可以睡着。大鸟再来时，剩下的空比它的身子小，它放不进去，掉下来，扣一颗心。空要在画面上比大鸟窄，不能看起来还很空却把大鸟弹开。

小窝比大鸟窄时，大鸟一开始就放不进去，也会掉下来扣心。小鸟仍然可以睡进比自己宽的窝。所以先把小鸟送进大窝，会把大鸟的位子占掉。这是顺序，不是再认一次颜色。前期关卡先不使用。

睡着的鸟不下来。没睡着的鸟会跳下或掉下。不要做水管排序的倒进倒出。

## 6. 故意不做

- 落点变成下一发的弹弓
- 连续攀爬、镜头跟着鸟、会消失的桩
- 实时抛物线
- 用羽毛或其他换算物代替直接扣心
- 错窝的鸟一直坐到重来，逼玩家一次射对
- 用窝沿大小决定鸟留不留下
- 一个普通窝坐多只鸟
- 生命、失败等待、倒计时
- 倒塌、破坏量、连锁计分
