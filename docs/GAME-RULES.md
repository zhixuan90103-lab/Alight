# Alight

英文名 **Alight**：鸟落下并停住。不用 Sling、Angry、Shot。

配套：[AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

> 玩法尚未实现。本文是当前规则，供关卡和原型使用。  
> 场地是底座的竖屏一屏（设计空间 390×844）。镜头不跟鸟走。

## 1. 故事

风把一群还不会自己飞的鸟从岭上掀下来。岭上的窝亮着各自的颜色。玩家用弹弓把鸟送回去。

鸟落到自己的窝里，就蜷好睡着，灯暗下去。落到别的窝里，站一下再跳下来，灯不暗。

鸟不是武器。没有袭击对象。倒塌不计分，也不作为结束条件。

颜色用来认出这是谁的家，不做成配色题。体型决定鸟有多重、同一下拉力飞多远。前期不靠体型决定它能不能留下。

## 2. 每一关都成立

- 画面固定。弹弓和窝同时看得见。前期全场只有一把弹弓。
- 每一发都从这把弹弓拉开再松手。方向和力度一起决定。松手后鸟不再挂在绳子上。落点不是下一发的起点。
- 不画这一发的抛物线。刚刚这只鸟的飞行留下残影，用来改下一拉。换一只鸟，残影清掉。
- 操作在下半屏。拉力的提示画在手指上方。
- 一样大就一样重。轻鸟同一下拉力飞得更高，重鸟飞得更近。
- 可以整关重来。重来后心和鸟的安排都恢复。没有等待时间。

## 3. 窝

前期每个普通窝只留一只鸟。鸟留不留下，看这是不是它自己的窝，不看身子卡不卡在沿上。

- 落到自己的窝里：睡着，灯暗，不再下来。
- 落到别的窝里：站一下，跳下去，灯不暗，窝空出来。
- 窝里已经睡着鸟：后来的鸟碰到它就离开，不挤进去。
- 力度不够：掉在窝前面。力度太大：飞过窝再落下。

没睡着的鸟落到画面低处。弹弓在低点。心里还有剩，鸟沿下坡滚回弹弓，不用再按一次召回。心已经没有了，鸟落地后播一段消失动画，然后从画面上拿掉，不留在地上，也不睡着。

共用窝是后期才出现的特殊窝。它更深，有多根栖木，空位看得见，只收这一关指定的那几只，通常是同色的一家。每睡下一只，空位少一个。不是这一窝的鸟即使还有空位，也只站一下就跳下去。

## 4. 心和评级

每一关一开始就有三颗心，画在画面上。三颗心整关共用。

- 鸟在自己的位子上睡着，心不变。
- 没睡着而回到低处，扣一颗心。这包括力度不够、飞过窝、落到别的窝再跳下。
- 心里还有剩，鸟滚回弹弓，可以再拉。
- 这一下把最后一颗心扣没，鸟落地后消失，不再回到弹弓。之后再没睡着的鸟，落地后同样消失。
- 弹弓上没有待发的鸟，这一关结束。
- 结果同时看两样，并且都画出来：睡着的鸟有几只，心还剩几颗。最高是三只鸟都睡着、三颗心都在。少一只睡着的鸟，或少一颗心，都降一档。扣掉最后一颗心时鸟也不回来，这一下会降两档。

第一关只有该进的窝，没有别的窝可跳，但力度不够仍然扣心。

## 5. 关卡顺序

同一下拉开不变。前期每一关改的是窝的位置和鸟的体重，让上一关的拉力不够用。

1. 一个共用窝，三只鸟，只改远近。
2. 仍是一个窝，鸟分成轻和重。
3. 多个单鸟窝，颜色不同。落到自己的窝里睡着，落到别的窝里跳下并扣心。
4. 更好射的那个窝是别人的。跳下去扣心。
5. 共用窝带空位，再加上单鸟窝。只有该睡的空位会把鸟留下。

这一批之后，只换位置会重复。可以再加一种仍用拉开的局面，例如只挡住高弧的树枝，或整关不变的侧风。有侧风时，同一只鸟的残影仍然有效。

### 后期才用

多处起点先不做。若使用，窝在一侧，弹弓在对面高低不同的崖上。一只鸟整关只站一个起点，残影才不会指错。每个起点都必须真能把这只鸟送进它该进的窝。

窝口大小也先不做。若使用，它是看得见的容量，不是「卡不卡沿」。同一个颜色可以有大窝和小窝。小鸟落到大窝里，剩下的空还比它宽，可以睡着。大鸟再来时，剩下的空比它的身子窄，放不进去，掉下来，扣一颗心。画面上的空必须已经比大鸟窄。先把小鸟送进大窝，会把大鸟的位子占掉。这是顺序，不是再认一次颜色。

不要做水管排序的倒进倒出。睡着的鸟不下来。

## 6. 故意不做

- 落点变成下一发的弹弓
- 连续攀爬、镜头跟着鸟、会消失的桩
- 实时抛物线
- 用羽毛或其他东西代替直接扣心
- 错窝的鸟一直坐到重来
- 用看不见的窝沿判定把鸟卡住或漏下去
- 前期一个普通窝睡多只鸟
- 失败后的等待、倒计时
- 倒塌、破坏量、连锁计分
