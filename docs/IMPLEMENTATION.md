# Alight 实现

配套：[GAME-RULES.md](./GAME-RULES.md) · [AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

第一关原型在 `src/game/`。这一关是三颗轻球、三条皮筋、三只口袋，上下各排成一行。每只口袋收一颗。错色、星、残影、音效还没做。口袋的做法以本文第 7 节为准，画面以第 10 节为准。其余规则以 [GAME-RULES.md](./GAME-RULES.md) 为准。

## 1. 放在哪

| 职责 | 位置 |
|------|------|
| 默认参数、端点、下沉 | `src/game/tune.ts` |
| 画面上的参数面板 | `src/game/tunePanel.ts`，挂在 `#ui-root` |
| 拉、出手、飞行、接住、心 | `src/game/sim.ts` |
| 口袋的形状、进袋、外轮廓 | `src/game/bag.ts` |
| 皮筋形状 | `src/game/band.ts` |
| 画面 | `src/game/view.ts` |
| 设计坐标和世界坐标 | `src/game/frame.ts` |
| 启动、手指、震动 | `src/main.ts` |
| 心 | `#ui-root` |
| 物理 | `@dimforge/rapier2d-compat`，只在 `src/game/` 里用 |

舞台、安全区、设计尺寸 390×844 仍走 `src/adapt/`。WebGPU 仍走 `src/create-renderer.ts`。

音效按 [AUDIO.md](./AUDIO.md)，这次不做。震动在拉开、松手、接住、睡着、扣心，以及球明显撞上碗壁时各一下，不每帧震。

## 2. 动画和结算

操作优先见 [GAME-RULES.md](./GAME-RULES.md) 第 0 节。代码里，只有 `settling`（进袋直到停稳）和心扣没后的 `gone` 不接受这颗球的拉。其余状态手都可以打断。结算不锁旁边还有球的皮筋。

| 段 | 状态 | 手指 |
|----|------|------|
| 动画 | `launching` 收回、`flying` 飞行、`catching` 回弹、`returning` 扣心后等放回托 | 托心周围约 90 像素可以打断。回弹时按的是球。球停在手指处，开始新的一拉。不扣心，不进袋 |
| 结算 | `settling` 进袋直到停稳，然后留在碗里；最后一颗心之后的 `gone` | 这一颗拉动无效 |

飞行中按的是原来的托，不是天上的球。回弹中按的是球当时的位置。被别的皮筋接住时，打断之后球算那根皮筋的。

## 3. 坐标和时间

手指先经过舞台的包围盒换成设计坐标，忽略 letterbox 外面的点。玩法内部向右为正、向上为正。画到 Three.js 时不再翻一次。

相机正投影，固定盖住 390×844。镜头不跟球。

模拟每步 1/60 秒。从后台回来，一次最多补 0.25 秒。画面画最近一步的位置，不在两步之间插值。

Rapier 的 `lengthUnit` 是 80。不改的话，像素速度会被夹掉。

## 4. 三个数

下沉和松手速度只从劲度、质量、重力来，不另写一套。画面右上角的参数面板改的是这一局，不写回文件。默认值如下。

| 项 | 默认 | 单位 |
|----|------|------|
| 皮筋劲度 | 150 | 拉力 = 劲度 × 拉长 |
| 基础质量 | 1 | 最轻的球。更重的球是它的倍数 |
| 全局重力 | 3800 | 设计像素 / 秒² |
| 阻尼 | 0.30 | 接住和空皮筋收回时的衰减 |
| 口袋阻尼 | 0.60 | 面板里还在。硬 U 不用它 |
| 皮筋粗细 | 7 | 像素。满拉留下约七成 |
| 球半径 | 18 | 像素。直径 36，小于相邻皮筋之间的空档 |
| 画面铆钉半径 | 描边 × 0.34 | 约 2.7 像素。只用于画面，不挡球 |
| 皮筋半宽 | 32 | 像素。从托心到一侧铆钉 |

由此得到：

- 下沉 = 质量 × 重力 / 劲度。球的质量为 1 时约 25.3 像素。
- 空皮筋的质量是球的九分之一，下沉约 2.8 像素，所以没球时更紧。
- 松手速度 = 拉长 × √(劲度 / 球的质量)。方向指向没被拉开的托。手指速度不算。
- 死区 28 像素。短于死区就退回，不发射。
- 向下和两侧的最大拉动幅度，是托到地面上方停住的这段距离，现在是 166 像素。不能拉进地面。
- 向上时皮筋不停在拉直。它最高就是没球时的默认弧。球压到这条弧上之后，皮筋不再跟着升。
- 球还可以再向上 18 像素。再往上就脱手：从当时的位置只受重力下落，落回这条默认弧，再被接住坐回托。不按松手发射，不扣心。手指还按着也不算新的一拉，要先抬手。

## 5. 皮筋和铆钉

两端各一颗铆钉，钉在托的斜上方。不是分叉弹弓。皮筋是白色，铆钉是黑色。三根皮筋的 x 是 78、195、312，托的 y 是 612。相邻两颗内侧铆钉之间约 43 像素，大于球的直径，球可以从这道缝里掉下去。

铆钉：

- 固定，不接球，不扣心，也不算落上皮筋。
- 不挡球。拉、收回、飞行、接住回弹都可以穿过铆钉。画面上的圆头仍然在。
- 两颗铆钉的连线是这根皮筋的直径。连线以上是上侧。接球只看这个，不看绳子垂在哪一侧。

带子：

- 整根 29 个点。球压在上面时，两边各 4 段直线，贴球的弯分成 20 段。内缘贴住球，中间不留缝。空着的浅弧也用这 29 个点。
- 球离开后，整条是一条绷紧的浅弧，用空皮筋自己的下沉。收回时会略微冲过，再停住。
- 拉动时两边贴直，贴球的弧朝向这一下拉力，沿切线接上，不收成贴在球边上的尖角。两端之间向上抬时，弧留在球下，不翻过球顶。没拉时弧朝重力。接住回弹时弧跟着球慢慢转。
- 切线穿球、两边交叉，或弧要翻过半圈时，不把弧缩成一个点。缩成一个点会从铆钉穿出球外，变成一根尖。每一侧各自连到自己的切点。铆钉在球里，才不拉这一侧，弧从球边开始。
- 描边的圆角半径是半个粗细。不用斜接。折返回来的点丢掉。
- 拉得越满，皮筋越细，满拉留下约七成。不变色，球不变形。拉到最大幅度时，球和皮筋一起沿拉力方向轻抖，幅度 1.6 像素，两端不动。抖动不改变松手速度。

松手之后：

1. 托点用皮筋自己的小质量收回，球还在托上。
2. 回到托时球脱离，速度用上面的公式，质量用球的质量。
3. 空皮筋留着收回的速度，整条弧弹回去。
4. 脱离之后球只受重力，直到进袋、被皮筋接住，或落地。

## 6. 接住

空皮筋，包括刚射出的自己那根，用同一条接球规则。球这一步之前没有碰到这根皮筋，这一步碰到了，并且出发位置在这根铆钉连线的上侧，才接住，并改坐到那根托上。出发位置在连线上或下侧，不接。出手那一下球在连线下面，而且常常还贴着收回的皮筋，所以不会刚离开就被接回去。托上还有球，或者这根正在接别的球，不接。

接住时球还带着碰上的速度。同一条劲度把它拉回托，幅度自己变小。晃动小到看不出来才停在托上。接住不扣心。

飞着的球砸到另一根皮筋上的球时，那颗球和它的皮筋按碰上的速度晃一下，再荡回托上。轻碰幅度小，撞得快就荡得远。这是回弹，手可以按住这颗球打断。托上没有球的皮筋不会因此凭空多出一颗。

落在皮筋外面、掉到地上或飞出画面，扣一颗心。心还在就放回托上。心没了，这一发结束。放回托的等待可以打断。最后一颗心扣没后的消失不能打断。

## 7. 口袋

这一关的目标是三只开口向上的硬 U。左右两只在设计坐标 y = 268，中间一只在 y = 428。x 是 78、195、312。每只只收一颗。两边是直壁，底部是半圆。内口半宽是 1.7 个球半径，直壁高度是 3.2 个球半径。球停在圆底上，左右留空。描边在内边外面。碗口上方写当前球数和容量：球正在这只碗里是 1/1，否则是 0/1。同一帧两颗都进不同的空碗，左边先算。面板里的「蓝色袋子」可以一起关掉。

下面三根皮筋用同一行的 x，托的 y 是 612。每根托上有一颗球。空托不能拉。

口袋和球在同一层。两壁之间、碗口以上是空的。球心向下穿过碗口才算进碗。

- 进碗：穿过碗口的那一帧，球放在刚穿过的位置，来速不削。这一步剩下的路程继续撞碗壁。朝内壁的速度留下约四成，贴壁的速度每碰一次留下约九成六。重力还在。撞得明显时轻震一下。离圆底 2 像素以内、速度低于 36 像素/秒，就停在圆底，状态变成 `asleep`。碗、球和 1/1 留在原地。从进碗到停稳不能拉这颗。停进碗不扣心。
- 离开：球已经在碗口之上、远在碗底之下，或横着离开碗，并且没有贴着碗壁，这只碗重新打开，数字回到 0/1，球继续飞。
- 外面：硬边。球心被推到壁外，朝壁的速度留下约两成。碗不塌陷。不进碗，不扣心。
- 已经有球的碗：内壁和碗口都是硬边，不收第二颗。再撞上去按外面弹开。

## 10. 画面

平涂，无灯光，无高光。正投影。颜色写在 `src/game/view.ts`，心和参数面板用 `src/style.css` 里同一套。

| 物 | 色 |
|----|----|
| 背景，含舞台外的留白 | `#4777cc` |
| 口袋 | `#79d0ff` |
| 皮筋 | `#ffffff` |
| 铆钉 | `#111111` |
| 球，以及点满的心 | `#faca50` |
| 投影 | `#3862ae`，不透明 |

描边是 8 像素的均匀细线，两端圆头。这个线宽只用于画面。第 4 节的皮筋粗细 7 像素仍是绳子的物理粗细，满拉变细不改这条描边。

投影是形状沿右下扫出的一块实心面，不是把轮廓再平移一份。方向是向右 14 像素、向下 14 像素。口袋用这个全长。皮筋和球用 0.6 倍。靠近物体的一边是硬边。只有最远端有淡出，长度是该投影长度的 10%，只顺着投影方向。原形盖在影子的起点上。

心在左上，空心是口袋的蓝色描边，点满是球的金色。参数面板用同一套蓝。
