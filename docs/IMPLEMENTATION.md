## 2. 动画和结算

操作优先见 [GAME-RULES.md](./GAME-RULES.md) 第 0 节。一根皮筋最多一颗球。`ready`、`pulling`、`launching`、`catching` 表示球还在这根皮筋上，按球可以拉。`flying` 和 `returning` 表示皮筋是空的，不能拉，但空皮筋仍能接球。这一关没有心，固定 `LEVEL_BALLS`（5）颗。开局皮筋是空的，`OPEN_DELAY` 后第一颗从 `EXIT` 落到皮筋上。飞行中球心飞出画面左侧、右侧或下沿，连续 0.3 秒后死亡；这 0.3 秒里飞回画面就重新计时。往上飞出不死亡。整颗球落到碗口以下（球心低于碗口一个半径）立刻结算。死亡后立刻补下一颗。进碗后再等 0.5 秒。这个颜色的每只碗都已经有同色球，就不再补这个颜色。还有余量且颜色未完成时，下一颗出现在皮筋正上方的 `EXIT`（设计坐标 y 526），速度为 0，自由落到皮筋上，由空皮筋接住。余量用完，或这个颜色已经完成，皮筋空着。进碗的球不等它停稳，留在碗里继续受物理。往上飞出不结算。离开左、右或下沿满 0.3 秒进入 `gone`。`settling`、`asleep`、`returning`、`emerging` 还留在类型里，这一关没有入口。

| 段 | 状态 | 手指 |
|----|------|------|
| 还在皮筋上 | `launching` 收回、`catching` 回弹 | 按球可以打断，距离约 90 像素。球停在手指处，开始新的一拉。不扣心 |
| 皮筋已空 | `flying` 飞行。离开左、右或下沿满 0.3 秒后是 `gone` | 不能拉。空皮筋仍可接球 |

飞行中球已经离开皮筋，按空托不能拉。回弹中按的是球当时的位置。被别的皮筋接住时，球坐上那根皮筋，原来的皮筋变空。

接球和皮筋形状分开。空皮筋只在球的竖直速度向下、球在铆钉连线之上、并且是新碰上时接住。发射速度朝托，拉下去的球是向上飞的，不会被自己的皮筋接住。改长度、铆钉或粗细，都不改变这条。

## 3. 坐标和时间

手指先经过舞台的包围盒换成设计坐标，忽略 letterbox 外面的点。玩法内部向右为正、向上为正。画到 Three.js 时不再翻一次。

相机正投影，盖住 390×844。镜头固定在画面中心，横向是 0，纵向也不动。球飞出上沿后画面不跟着升。

模拟每步 1/60 秒。从后台回来，一次最多补 0.25 秒。画面画最近一步的位置，不在两步之间插值。

Rapier 的 `lengthUnit` 是 80。不改的话，像素速度会被夹掉。

## 4. 三个数

下沉和松手速度只从劲度、质量、重力来，不另写一套。画面右上角的参数面板改的是这一局，不写回文件。默认值如下。

| 项 | 默认 | 单位 |
|----|------|------|
| 皮筋劲度 | 200 | 拉力 = 劲度 × 拉长 |
| 基础质量 | 1 | 最轻的球。更重的球是它的倍数 |
| 全局重力 | 3800 | 设计像素 / 秒² |
| `BAND_ZETA` | 0.30 | 只用于接住回弹和空皮筋收回 |
| 口袋弹性 | 0.4 | 木碗碰撞体，和竖板弹性相同。面板可改 |
| 木板弹性 | 0.4 | 竖板自己的材料，不跟口袋弹性走。摩擦默认 0.4。面板可改 |
| 木碗摩擦 | 2 | 同时是这块木板的阻尼。面板可改 |
| 球摩擦 | 1 | 面板可改。接触取两边里较大的那个 |
| 球空气阻尼 | 0 | `linearDamping`。飞行没有阻力 |
| 皮筋粗细 | 7 | 像素。满拉变细 0.6，留下四成 |
| 球半径 | 18 | 像素。直径 36，小于相邻皮筋之间的空档 |
| 画面铆钉半径 | 描边 × 0.34 | 约 2.7 像素。只用于画面，不挡球 |
| 皮筋长度 | 100 | 像素。两颗铆钉的距离。球在中点。最大拉动是长度的 1.1 倍，默认 110 像素 |

由此得到：

- 球永远在两颗铆钉的中点。皮筋长度是铆钉之间的距离，默认 100 像素，面板可以改。改长度时球留在中点，两颗铆钉一起张开或收拢。
- 下沉 = 质量 × 重力 / 劲度。只跟球的重量有关。球的质量为 1 时是 19 像素。长度不改下沉。
- 空皮筋的质量是球的九分之一，下沉约 2.1 像素，所以没球时更紧。
- 最大拉动距离 = 皮筋长度 × 1.1。默认长度 100 像素，球最多离开托 110 像素。皮筋更长，这个上限一起变大。
- 手指离开托的距离是 f，上限 200 像素。球沿同一方向离开托。f 很小时球和手指一样远。f 到 200 时球刚好 110。再远球停在 110。默认时手指 40 像素，球约 35；手指 96 像素（第一关往右碰到画面边），球约 71。
- 松手速度 = (球离开托的距离 / 最大拉动) × 皮筋长度 × 1.6 × √(劲度 / 球的质量)。默认拉满时等于拉开 160 像素。方向指向没被拉开的托。手指速度、手指离开托的距离都不算。下沉仍用劲度，不跟这次的发射长度变。
- 死区 28 像素，按球离开托的距离。短于死区就退回，不发射。
- 向上时皮筋不停在拉直。它最高就是没球时的默认弧。球压到这条弧上之后，皮筋不再跟着升。
- 球还可以再向上 18 像素。再往上就脱手：从当时的位置只受重力下落，落回这条默认弧，再被接住坐回托。不按松手发射，不扣心。手指还按着也不算新的一拉，要先抬手。

## 5. 皮筋和铆钉

两端各一颗铆钉，钉在托的斜上方。不是分叉弹弓。皮筋是白色，铆钉是 `#777268`。第一关只有最右边一根，x 是 312 再向左半个球（294），托的 y 是 612。

铆钉：

- 固定，不接球，不扣心，也不算落上皮筋。
- 不挡球。拉、收回、飞行、接住回弹都可以穿过铆钉。画面上的圆头仍然在。
- 两颗铆钉的连线是这根皮筋的直径。连线以上是上侧。接球只看这个，不看绳子垂在哪一侧。

带子：

- 整根 29 个点。球压在上面时，两边各 4 段直线，贴球的弯分成 20 段。内缘贴住球，中间不留缝。空着的浅弧也用这 29 个点。
- 球离开后，整条是一条绷紧的浅弧，用空皮筋自己的下沉。收回时会略微冲过，再停住。
- 拉动时两边各是一条直线，从铆钉连到球上的切点。贴球的弧只走朝向这一下拉力的短边，不超过半圈，弧的中点离拉力方向不超过 90°。直线在切点上接入弧，不在球边另拐一下，也不翻过球顶。切线穿进球里、两边交叉、或短弧不朝向拉力的接法不用。
- 球在两颗铆钉之间并高于托时，弧仍朝下，停在没球时的默认弧，不跟着球翻过球顶。没拉时弧朝重力。接住后球还在默认弧以下时，杯口朝下。升过默认弧之后绳子不再跟着球。
- 铆钉在球里，这一侧没有切线，就不画这一侧。不把缺掉的一侧收成一个点，也不从铆钉穿出球外。
- 描边的圆角半径是半个粗细。不用斜接。折返回来的点丢掉。
- 拉得越满，皮筋越细，满拉变细 0.6，留下四成。不变色，球不变形。手指一离开托，球和皮筋就沿拉力方向轻抖，两端不动。幅度和频率都按手指离开托的距离除以上限 200。拉满幅度是 1.6 像素，频率大约每秒 10 次。拉得越短，频率越慢。抖动不改变松手速度。

松手之后：

1. 托点用皮筋自己的小质量收回，球还在托上。
2. 回到托时球脱离。皮筋仍沿玩家拉的方向收回。球的速度在这一拍决定，质量用球的质量。规则见下面的「出手帮助」。
3. 空皮筋留着收回的速度，整条弧弹回去。
4. 脱离之后球只受重力，直到进袋、被皮筋接住，或球心离开画面左、右、下沿满 0.3 秒。下沿是世界 y = 0。镜头固定。没有地面。往上飞出不结束飞行。死亡后立刻补球。进碗后再等 0.5 秒。飞行中不再改出手速度。

### 出手帮助

判定在 `assistRelease`（`src/game/aim.ts`）。`Sim` 只在球脱离托的那一拍调用。`SHOW_HINT` 为真时不调用，速度就是这一拉。死区和向上脱手不进这里。

帮助不画出来。皮筋收回的方向仍是玩家拉的方向。参数面板没有这一档。

| 项 | 值 |
|----|----|
| `AIM_ANGLE` | 1.25°。框的半宽 |
| `AIM_SPEED` | 这一发速率的 3.5%。框的半宽 |
| 拉满上限 | `launchSpeed(MAX_PULL)`。已经拉满只能减，不能再快 |
| 角度代价 | 速率那一项的 4 倍。力度能进碗就不动角度 |
| 采样 | 角度和速率各 9 档，含原来的那一档。步长是半宽的四分之一 |
| 预测时长 | 2.4 秒。每步物理再分成 4 小步 |

搜索用当前的重力、空气阻尼和弹性。碗壁、竖板、折板按现在的碰撞体。胶囊停在松手那一拍的角度，预测里不再摆。空皮筋用静止时的弧，接住规则和游戏相同：正在下落、新碰上、出发位置在铆钉连线之上。碗里已经停着的球、另一颗正在飞的球，都不放进这次预测。

一档算出整颗球进了某只碗，才算这个解。碗必须和球同色。框里只有一只这样的碗时，取得分最低的解。得分是速率差和角度差各自除以半宽之后的平方，角度再乘 4。原来那一拉得分是 0，已经能进就保持原速度。两只同色碗都有解，或者只有错色碗有解，就保持原速度。飞出去之后不再改。

`scripts/aim-check.ts` 用第一关的一条弹道检查：差一点力度会补进碗，差得多不改，已经能进的不改，也不会超过拉满速率。运行是 `npx tsx scripts/aim-check.ts`。

## 6. 接住

空皮筋，包括刚射出的自己那根，用同一条接球规则。球这一步之前没有碰到这根皮筋，这一步碰到了，并且出发位置在这根铆钉连线的上侧，才接住，并改坐到那根托上。出发位置在连线上或下侧，不接。出手那一下球在连线下面，而且常常还贴着收回的皮筋，所以不会刚离开就被接回去。托上还有球，或者这根正在接别的球，不接。

接住时球还带着碰上的速度。接住的劲度是拉动的 2 倍，默认 400。球压下去再弹回来，阻尼让下一次更小。晃动小到看不出来才停住。停住时球心比托高 5 像素，绳子跟着球。接住不扣心。

铆钉固定在托上方 12 像素。绳子中线绕在球外，内缘贴住球，不穿进球里。空皮筋的中点只比铆钉低大约 2 像素。玩家拉开时绳子是拉直的切线，劲度仍是 200。

回弹和向上拖用同一条上限：没球时的默认弧，再向上 `SLIP_LIFT`（18 像素）。球还低于默认弧时，绳子托着它，杯口朝下，两边仍是切线。越过默认弧后，绳子留在默认弧，不再粘着球。球心超过上限就离开绳子，速度清零，从这条线上自由落下，再由空皮筋接住。这一下不发射，不扣心。手指拖出去会震一下。回弹脱手不另震。

飞着的球砸到另一根皮筋上的球时，那颗球和它的皮筋按碰上的速度晃一下，再荡回托上。轻碰幅度小，撞得快就荡得远。这是回弹，手可以按住这颗球打断。托上没有球的皮筋不会因此凭空多出一颗。

落在皮筋外面也不结束飞行。球心离开画面左、右或下沿，连续 0.3 秒后进入 `gone`，球消失，并立刻补下一颗。飞回画面就重新计时。镜头固定，不跟球，也不左右偏。没有心。

## 7. 口袋

第一关只留最左边一只开口向上的硬 U。设计坐标 x = 117.6，y = 268。先从 78 向右移了半个碗宽，再向左收回一个球半径。两边是直壁，底部是半圆。内口半宽是 3.2 个球半径，直壁高度是 4.6 个球半径。口宽够三颗并排，直壁够再叠一层，所以五颗球能停在里面。规则不限制人数。描边在内边外面。碗口上方不写数字。面板里的「蓝色袋子」可以关掉。

下面只有最右边一根皮筋，x = 312 再向左半个球（294），托的 y 是 612。开局托上没有球。空托不能拉。

刚体接触只用 Rapier。一份材料是弹性、摩擦、阻尼，写在 `src/game/material.ts`。

1. 木碗和以后的障碍是静态碰撞体。弹性和摩擦写在碰撞体上，组合规则是 `Max`，所以在当前这些数里用的是固件自己的数。静态刚体的线阻尼不会作用到球上。固件的阻尼定义为它的摩擦系数，数值相同。这一关没有地面。
2. 球的材料用于没有固件的接触，以及飞在空气里的 `linearDamping`。默认线阻尼是 0。球的弹性和摩擦组合规则是 `Average`。
3. 木碗弹性 0.4，摩擦和阻尼 2。球弹性 0.05，摩擦 1，空气阻尼 0。竖板是另一份材料，弹性也是 0.4，摩擦 0.4。这几项在参数面板里可以改，改其中一个不会带动另一个。
4. U 的底是碰撞体，口上没有碰撞体。球不能从底漏出去，可以从口离开。不封口，不按人数拒绝。
5. 碗口不画数字。
6. 皮筋不是这份刚体材料。它保留劲度、`BAND_ZETA` 和绳子质量。拉、接、出手瞬移仍是运动学例外。接触传导以后再做。
7. 计数和以后的颜色只读物理状态。颜色不改碰撞。同一只碗里的球彼此碰撞。已经落进碗里的球留在碗里，重叠修正不会把它推出碗壁。这一关没有心。死亡不放回皮筋。

## 8. 界面

这一关不画心，不写关卡号，不用白牌。界面都在 `src/game/hud.ts`。

**局内**

- 左上是 `LEVEL_BALLS` 颗白色圆点，颗数是这一关的总球数，不按球的颜色分色。开局都是实心白。每从出口掉出一颗，最左边一颗实心变成白色虚线圆环。圆点记的是已经离开出口的颗数，不是死亡。
- 右上四颗 40×40 的白圆钮，正圆，影子向右下。图案是 Phosphor Light：重玩 `arrow-clockwise`，跳关 `arrow-right`，提示 `eye`，设置 `gear`。从左到右是重玩、跳关、提示、设置。深灰、50% 透明度，在圆里居中。提示打开后图案不透明，并带上 `is-on`。设置打开参数面板。重玩清碗，库存回到这一关的球数，皮筋先空着，再从出口掉第一颗，镜头回到低机位。跳关进入下一关；已经在最后一关时回到第一关。结算弹出时这四个钮先藏起来。

## 11. 震动

真机才有马达。桌面调用会空过。信号在 `src/game/sim.ts` 里记一帧，`src/main.ts` 读走。拉动的持续震动在 `src/game/pullHaptics.ts`。不每帧震。

| 时机 | 震动 |
|------|------|
| 按住球拉动 | 持续震动。强度 0.1 到 0.4，锐度 0.1 到 0.2，按拉长占最大拉动的比例线性增加。比例变化不到 0.02 不更新 |
| 拉长比例达到 0.6 | 在持续震动上再叠碎抖。强度 0.3，锐度 0，频率 25 Hz。低于 0.6 就停掉这层 |
| 松手、向上脱手，或不再处于 `pulling` | 停掉持续震动和碎抖 |
| 空皮筋接住 | 一下轻震，`impact('light')` |
| 飞着的球砸到皮筋上已有的球 | 一下轻震 |
| 球的碰撞体刚碰上木碗 | 一下轻震。贴着碗滑不重复。弹开再碰上再震一下。球和球相撞不走这一下 |
| 松手发射 | 一下中等，`impact('medium')` |
| 向上拖过上限而脱手 | 一下 `impact('rigid')`。回弹自己越过上限不震 |

进碗结算、球出生、球死亡，都不震。
