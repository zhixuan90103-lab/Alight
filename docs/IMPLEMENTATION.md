# Alight 实现

配套：[GAME-RULES.md](./GAME-RULES.md) · [AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

第一关原型在 `src/game/`。这一关是一颗轻球、一条皮筋、一个同色半圆。队列、错窝、星、残影、音效还没做。规则以 [GAME-RULES.md](./GAME-RULES.md) 为准。

## 1. 放在哪

| 职责 | 位置 |
|------|------|
| 三个锁定数、端点、下沉 | `src/game/tune.ts` |
| 拉、出手、飞行、接住、窝、心 | `src/game/sim.ts` |
| 皮筋形状 | `src/game/band.ts` |
| 画面 | `src/game/view.ts` |
| 设计坐标和世界坐标 | `src/game/frame.ts` |
| 启动、手指、震动 | `src/main.ts` |
| 心 | `#ui-root` |
| 物理 | `@dimforge/rapier2d-compat`，只在 `src/game/` 里用 |

舞台、安全区、设计尺寸 390×844 仍走 `src/adapt/`。WebGPU 仍走 `src/create-renderer.ts`。

音效按 [AUDIO.md](./AUDIO.md)，这次不做。震动只在拉开、松手、接住、睡着、扣心时各一下，不每帧震。

## 2. 坐标和时间

手指先经过舞台的包围盒换成设计坐标，忽略 letterbox 外面的点。玩法内部向右为正、向上为正。画到 Three.js 时不再翻一次。

相机正投影，固定盖住 390×844。镜头不跟球。

模拟每步 1/60 秒。从后台回来，一次最多补 0.25 秒。画面画最近一步的位置，不在两步之间插值。

Rapier 的 `lengthUnit` 是 80。不改的话，像素速度会被夹掉。

## 3. 三个锁定数

画面上的端点位置不反过来改这三个数。

| 项 | 值 | 单位 |
|----|----|------|
| 皮筋劲度 | 43 | 拉力 = 劲度 × 拉长 |
| 基础质量 | 1 | 最轻的球。更重的球是它的倍数 |
| 全局重力 | 1700 | 设计像素 / 秒² |

由此得到：

- 下沉 = 质量 × 重力 / 劲度。球的质量为 1 时约 39.5 像素。
- 空皮筋的质量是球的九分之一，下沉约 4.4 像素，所以没球时更紧。
- 松手速度 = 拉长 × √(劲度 / 球的质量)。方向指向没被拉开的托。手指速度不算。
- 死区 28 像素。短于死区就退回，不发射。
- 向下和两侧的最大拉动幅度，是托到地面上方停住的这段距离，现在是 158 像素。不能拉进地面。
- 向上时皮筋不停在拉直。它最高就是没球时的默认弧（约下沉 4.4 像素）。球压到这条弧上之后，皮筋不再跟着升。
- 球还可以再向上 18 像素。再往上就脱手：从当时的位置只受重力下落，落回这条默认弧，再被接住坐回托。不按松手发射，不扣心。手指还按着也不算新的一拉，要先抬手。

## 4. 皮筋

两端钉在托的斜上方。不是分叉弹弓。

- 球压在上面：两边是直线，只有贴着球底的一段顺着球面弯。内缘贴住球，中间不留缝。
- 球离开后：整条是一条绷紧的浅弧，用空皮筋自己的下沉。收回时会略微冲过，再停住。
- 拉动：向下和两侧，两边贴直，托球的弧朝向这一下拉力。向上时弧不翻过球，皮筋停在没球时的默认弧。没拉时弧朝重力。接住回弹时弧跟着球慢慢转。
- 拉得越满，皮筋越细。满拉留下约七成粗细。不变色，球不变形。拉到最大幅度时，球和皮筋一起沿拉力方向轻抖，两端不动。

松手之后：

1. 托点用皮筋自己的小质量收回，球还在托上。
2. 回到托时球脱离，速度用上面的公式，质量用球的质量。
3. 空皮筋留着收回的速度，整条弧弹回去。
4. 脱离之后球只受重力，直到进窝、被皮筋接住，或落地。

## 5. 接住

球先飞离皮筋，再碰上，才算接住。刚离手的那一下不算。

接住时球还带着碰上的速度。同一条劲度把它拉回托，幅度自己变小。晃动小到看不出来才停在托上。接住不扣心。

落在皮筋外面、掉到地上或飞出画面，扣一颗心。心还在就放回托上。心没了，这一发结束。

## 6. 窝

这一关只有一个蓝色半圆，开口向上，和球同色。球的中心进入半圆后，重力关掉，速度逐帧变小，收到圆心再停住。这是泻力。半圆不是实心的碗。

停进窝不扣心。

## 7. 心

三颗心画在 `#ui-root` 左上，让开安全区。这一关共用。

## 8. 还没做

- 队列、残影、星、重玩、下一关
- 别人的窝、更大的窝、睡着的球互相挡住
- 树枝、平台、悬崖
- 音效
- 底边系统手势让给拉球

这些仍以规则文档为准，不提前塞进这一关。
