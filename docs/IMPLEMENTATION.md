# Alight 实现

配套：[GAME-RULES.md](./GAME-RULES.md) · [AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

第一关和第二关都在 `src/game/`。第一关是五颗金球、最右边一根皮筋、最左边一只大 U。第二关是三黄三蓝、正中一根同样高的皮筋、左上黄 U 和右上蓝 U，两只碗更小。能进几颗只看形状和物理。错色的球留在碗里。过关见第 8 节：每只碗里至少有一颗同色的球。残影和音效还没做。刚体材料以本文第 7 节为准，画面以第 10 节为准。其余规则以 [GAME-RULES.md](./GAME-RULES.md) 为准。关卡摆放和补球方式在 `loadLevelLayout`（`src/game/tune.ts`）。`REFILL_MODE` 为 `each-band` 或 `same-color`。`SLING_COLOR` 是每根皮筋补的颜色。

## 2. 动画和结算

操作优先见 [GAME-RULES.md](./GAME-RULES.md) 第 0 节。一根皮筋最多一颗球。`ready`、`pulling`、`launching`、`catching` 表示球还在这根皮筋上，按球可以拉。`flying` 和 `returning` 表示皮筋是空的，不能拉，但空皮筋仍能接球。这一关没有心，固定 `LEVEL_BALLS`（5）颗。开局皮筋是空的，`OPEN_DELAY` 后第一颗从 `EXIT` 落到皮筋上。飞行中球心掉到当前画面下沿以下，或整颗球落到碗口以下（球心低于碗口一个半径），就结算这一颗。不等它在碗里停稳。两种情况都再等 0.5 秒。停住的球留在碗里继续受物理。还有余量时，下一颗出现在皮筋正上方的 `EXIT`（设计坐标 y 472），速度为 0，自由落到皮筋上，由空皮筋接住。余量用完后皮筋空着。往上或往左右飞出不结算。掉出下沿进入 `gone`。`settling`、`asleep`、`returning`、`emerging` 还留在类型里，这一关没有入口。

| 段 | 状态 | 手指 |
|----|------|------|
| 还在皮筋上 | `launching` 收回、`catching` 回弹 | 按球可以打断，距离约 90 像素。球停在手指处，开始新的一拉。不扣心 |
| 皮筋已空 | `flying` 飞行。掉出下沿后是 `gone` | 不能拉。空皮筋仍可接球 |

飞行中球已经离开皮筋，按空托不能拉。回弹中按的是球当时的位置。被别的皮筋接住时，球坐上那根皮筋，原来的皮筋变空。

接球和皮筋形状分开。空皮筋只在球的竖直速度向下、球在铆钉连线之上、并且是新碰上时接住。发射速度朝托，拉下去的球是向上飞的，不会被自己的皮筋接住。改长度、铆钉或粗细，都不改变这条。

## 3. 坐标和时间

手指先经过舞台的包围盒换成设计坐标，忽略 letterbox 外面的点。玩法内部向右为正、向上为正。画到 Three.js 时不再翻一次。

相机正投影，盖住 390×844。横向始终是 0。低机位中心在画面中心。球的世界 y 还不超过 844 时停在低机位。超过 844 后，用 SmoothDamp 0.6 秒升到高机位。高机位固定上移 96，不按球的高度计算。球回到 844 以内后，用同一个时间回到低机位。

模拟每步 1/60 秒。从后台回来，一次最多补 0.25 秒。画面画最近一步的位置，不在两步之间插值。

Rapier 的 `lengthUnit` 是 80。不改的话，像素速度会被夹掉。

## 4. 三个数

下沉和松手速度只从劲度、质量、重力来，不另写一套。画面右上角的参数面板改的是这一局，不写回文件。默认值如下。

| 项 | 默认 | 单位 |
|----|------|------|
| 皮筋劲度 | 200 | 拉力 = 劲度 × 拉长 |
| 基础质量 | 1 | 最轻的球。更重的球是它的倍数 |
| 全局重力 | 3800 | 设计像素 / 秒² |
| `BAND_ZETA` | 0.30 | 只用于接住回弹和空皮筋收回 |
| 口袋弹性 | 0.25 | 木碗碰撞体。面板可改 |
| 木板弹性 | 0.4 | 竖板自己的材料，不跟口袋弹性走。摩擦默认 0.4。面板可改 |
| 木碗摩擦 | 2 | 同时是这块木板的阻尼。面板可改 |
| 球摩擦 | 1 | 面板可改。接触取两边里较大的那个 |
| 球空气阻尼 | 0 | `linearDamping`。飞行没有阻力 |
| 皮筋粗细 | 7 | 像素。满拉留下约七成 |
| 球半径 | 18 | 像素。直径 36，小于相邻皮筋之间的空档 |
| 画面铆钉半径 | 描边 × 0.34 | 约 2.7 像素。只用于画面，不挡球 |
| 皮筋长度 | 100 | 像素。两颗铆钉的距离。球在中点。最大拉动是长度的 1.6 倍，默认 160 像素 |

由此得到：

- 球永远在两颗铆钉的中点。皮筋长度是铆钉之间的距离，默认 100 像素，面板可以改。改长度时球留在中点，两颗铆钉一起张开或收拢。
- 下沉 = 质量 × 重力 / 劲度。只跟球的重量有关。球的质量为 1 时是 19 像素。长度不改下沉。
- 空皮筋的质量是球的九分之一，下沉约 2.1 像素，所以没球时更紧。
- 最大拉动距离 = 皮筋长度 × 1.6。默认长度 100 像素，最多拉 160 像素。皮筋更长，这个上限一起变大。
- 拉力 = 劲度 × 拉长。拉得更远，松手速度更大。松手速度 = 拉长 × √(劲度 / 球的质量)。方向指向没被拉开的托。手指速度不算。下沉不跟长度变。
- 死区 28 像素。短于死区就退回，不发射。
- 向上时皮筋不停在拉直。它最高就是没球时的默认弧。球压到这条弧上之后，皮筋不再跟着升。
- 球还可以再向上 18 像素。再往上就脱手：从当时的位置只受重力下落，落回这条默认弧，再被接住坐回托。不按松手发射，不扣心。手指还按着也不算新的一拉，要先抬手。

## 5. 皮筋和铆钉

两端各一颗铆钉，钉在托的斜上方。不是分叉弹弓。皮筋是白色，铆钉是 `#777268`。第一关只有最右边一根，x 是 312 再向左半个球（294），托的 y 是 612。

铆钉：

- 固定，不接球，不扣心，也不算落上皮筋。
- 不挡球。拉、收回、飞行、接住回弹都可以穿过铆钉。画面上的圆头仍然在。
- 两颗铆钉的连线是这根皮筋的直径。连线以上是上侧。接球只看这个，不看绳子垂在哪一侧。

带子：

- 整根 29 个点。球压在上面时，两边各 4 段直线，贴球的弯分成 20 段。内缘贴住球，中间不留缝。空着的浅弧也用这 29 个点。
- 球离开后，整条是一条绷紧的浅弧，用空皮筋自己的下沉。收回时会略微冲过，再停住。
- 拉动时两边各是一条直线，从铆钉连到球上的切点。贴球的弧只走朝向这一下拉力的短边，不超过半圈，弧的中点离拉力方向不超过 90°。直线在切点上接入弧，不在球边另拐一下，也不翻过球顶。切线穿进球里、两边交叉、或短弧不朝向拉力的接法不用。
- 球在两颗铆钉之间并高于托时，弧仍朝下，停在没球时的默认弧，不跟着球翻过球顶。没拉时弧朝重力。接住后球还在默认弧以下时，杯口朝下。升过默认弧之后绳子不再跟着球。
- 铆钉在球里，这一侧没有切线，就不画这一侧。不把缺掉的一侧收成一个点，也不从铆钉穿出球外。
- 描边的圆角半径是半个粗细。不用斜接。折返回来的点丢掉。
- 拉得越满，皮筋越细，满拉留下约七成。不变色，球不变形。拉到最大幅度时，球和皮筋一起沿拉力方向轻抖，幅度 1.6 像素，两端不动。抖动不改变松手速度。

松手之后：

1. 托点用皮筋自己的小质量收回，球还在托上。
2. 回到托时球脱离，速度用上面的公式，质量用球的质量。
3. 空皮筋留着收回的速度，整条弧弹回去。
4. 脱离之后球只受重力，直到进袋、被皮筋接住，或球心掉出当前画面下沿。下沿是镜头偏移 `look.y`，低机位是 0。没有地面。往上飞出不结束飞行。

## 6. 接住

空皮筋，包括刚射出的自己那根，用同一条接球规则。球这一步之前没有碰到这根皮筋，这一步碰到了，并且出发位置在这根铆钉连线的上侧，才接住，并改坐到那根托上。出发位置在连线上或下侧，不接。出手那一下球在连线下面，而且常常还贴着收回的皮筋，所以不会刚离开就被接回去。托上还有球，或者这根正在接别的球，不接。

接住时球还带着碰上的速度。同一条劲度把它拉回托，幅度自己变小。晃动小到看不出来才停在托上。接住不扣心。

回弹和向上拖用同一条上限：没球时的默认弧，再向上 `SLIP_LIFT`（18 像素）。球还低于默认弧时，绳子托着它，杯口朝下，两边仍是切线。越过默认弧后，绳子留在默认弧，不再粘着球。球心超过上限就离开绳子，速度清零，从这条线上自由落下，再由空皮筋接住。这一下不发射，不扣心。手指拖出去会震一下。回弹脱手不另震。

飞着的球砸到另一根皮筋上的球时，那颗球和它的皮筋按碰上的速度晃一下，再荡回托上。轻碰幅度小，撞得快就荡得远。这是回弹，手可以按住这颗球打断。托上没有球的皮筋不会因此凭空多出一颗。

落在皮筋外面也不结束飞行。球心掉出当前画面下沿才死亡：进入 `gone`，球消失。镜头不跟球，也不左右偏。球飞出开局画面上沿后才升到固定高机位（上移 96），落回这一屏后同样用 0.6 秒回来。没有心。

## 7. 口袋

第一关只留最左边一只开口向上的硬 U。设计坐标 x = 117.6，y = 268。先从 78 向右移了半个碗宽，再向左收回一个球半径。两边是直壁，底部是半圆。内口半宽是 3.2 个球半径，直壁高度是 4.6 个球半径。口宽够三颗并排，直壁够再叠一层，所以五颗球能停在里面。规则不限制人数。描边在内边外面。碗口上方不写数字。面板里的「蓝色袋子」可以关掉。

下面只有最右边一根皮筋，x = 312 再向左半个球（294），托的 y 是 612。开局托上没有球。空托不能拉。

刚体接触只用 Rapier。一份材料是弹性、摩擦、阻尼，写在 `src/game/material.ts`。

1. 木碗和以后的障碍是静态碰撞体。弹性和摩擦写在碰撞体上，组合规则是 `Max`，所以在当前这些数里用的是固件自己的数。静态刚体的线阻尼不会作用到球上。固件的阻尼定义为它的摩擦系数，数值相同。这一关没有地面。
2. 球的材料用于没有固件的接触，以及飞在空气里的 `linearDamping`。默认线阻尼是 0。球的弹性和摩擦组合规则是 `Average`。
3. 木碗弹性 0.25，摩擦和阻尼 2。球弹性 0.05，摩擦 1，空气阻尼 0。竖板是另一份材料，弹性 0.4，摩擦 0.4。这几项在参数面板里可以改，竖板不跟着口袋弹性走。
4. U 的底是碰撞体，口上没有碰撞体。球不能从底漏出去，可以从口离开。不封口，不按人数拒绝。
5. 碗口不画数字。
6. 皮筋不是这份刚体材料。它保留劲度、`BAND_ZETA` 和绳子质量。拉、接、出手瞬移仍是运动学例外。接触传导以后再做。
7. 计数和以后的颜色只读物理状态。颜色不改碰撞。这一关没有心。球心掉出画面下沿则死亡，不放回皮筋。

## 8. 界面

这一关不画心，不写关卡号，不用白牌。界面都在 `src/game/hud.ts`。

**局内**

- 左上是 `LEVEL_BALLS` 颗圆点。开局都是实心金色。每从出口掉出一颗，最左边一颗实心变成虚线圆环。圆点记的是已经离开出口的颗数，不是死亡。
- 右上三颗 40×40 的白圆钮，正圆，影子向右下。图案是 Phosphor Light：重玩 `arrow-clockwise`，跳关 `arrow-right`，设置 `gear`。从左到右是重玩、跳关、设置。深灰、50% 透明度，在圆里居中。设置打开参数面板。重玩清碗，库存回到这一关的球数，皮筋先空着，再从出口掉第一颗，镜头回到低机位。跳关进入下一关；已经在最后一关时回到第一关。结算弹出时这三个钮先藏起来。
- 碗口不画数字。

**结算**

球都离开之后再等 1 秒弹出。`Sim.result` 在每颗已出现的球都结束、并且没有在等补球时成立。这 1 秒里卡片还不出现。重玩会取消这次等待。每只碗里至少有一颗同色的球才是过关，否则失败。没有星。

遮罩是 `rgba(15, 23, 42, 0.45)`。中间一块圆角 16 的卡片，背景 `rgba(15, 23, 42, 0.92)`，内边距 22×28。卡片里上面是「过关」或「失败」，金色 `#ecbf77`。下面是重玩 `arrow-clockwise` 和下一关 `arrow-right`，和右上圆钮同一套。失败不画下一关。弹出时右上圆钮先藏起来。第一关的下一关调用 `Sim.loadLevel(2)`。第二关的下一关调用 `Sim.loadLevel(3)`。第三关的下一关调用 `Sim.loadLevel(4)`。第四关不画下一关。图标文件在 `public/icons/`，许可是 MIT。

## 10. 画面

平涂，无灯光，无高光。正投影。颜色写在 `src/game/view.ts`。局内圆钮、圆点、结算卡片和参数面板用 `src/style.css`。这一关不画心。

| 物 | 色 |
|----|----|
| 背景，含舞台外的留白 | `#7fa5bf` |
| 口袋 | 跟这只碗的球色。第一关和第二关的黄是 `#ecbf77`。第二关的蓝碗是 `#4d95dc` |
| 皮筋 | `#ffffff` |
| 铆钉 | `#777268` |
| 球 | 黄 `#ecbf77`，蓝 `#4d95dc` |
| 投影 | `#5f8096`，不透明 |

出口不画。球死亡或在 U 里停住后，下一颗从皮筋正上方自由落到皮筋上。

碗的描边是 8 像素的均匀细线，两端圆头。皮筋的画面粗细用 `bandWidth(strain)`，静止是 7 像素，满拉按「拉满变细」变细，默认留下约七成。影子和两端圆头跟着这条宽度。

投影是形状沿右下扫出的一块实心面，不是把轮廓再平移一份。方向是向右 14 像素、向下 14 像素。口袋用这个全长。皮筋和球用 0.6 倍。靠近物体的一边是硬边。只有最远端有淡出，长度是该投影长度的 10%，只顺着投影方向。原形盖在影子的起点上。

右上是重玩、跳关和设置三颗白圆钮，从左到右。图案是 Phosphor Light，深灰、50% 透明，和圆底之间没有影子。结算的下一关也用同一套。参数面板仍用这一套蓝。这一关没有心。

## 11. 震动

真机才有马达。桌面调用会空过。信号在 `src/game/sim.ts` 里记一帧，`src/main.ts` 读走。拉动的持续震动在 `src/game/pullHaptics.ts`。不每帧震。

| 时机 | 震动 |
|------|------|
| 按住球拉动 | 持续震动。强度 0.1 到 0.4，锐度 0.1 到 0.2，按拉长占最大拉动的比例线性增加。比例变化不到 0.02 不更新 |
| 拉长比例达到 0.6 | 在持续震动上再叠碎抖。强度 0.3，锐度 0，频率 25 Hz。低于 0.6 就停掉这层 |
| 松手、向上脱手，或不再处于 `pulling` | 停掉持续震动和碎抖 |
| 空皮筋接住 | 一下轻震，`impact('light')` |
| 飞着的球砸到皮筋上已有的球 | 一下轻震 |
| 球的碰撞体刚碰上木碗 | 一下轻震。贴着碗滑不重复。弹开再碰上再震一下。球和球相撞不走这一下 |
| 松手发射 | 一下中等，`impact('medium')` |
| 向上拖过上限而脱手 | 一下 `impact('rigid')`。回弹自己越过上限不震 |

进碗结算、球出生、球心掉出画面下沿，都不震。
