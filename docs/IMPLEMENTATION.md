# Alight 实现

配套：[GAME-RULES.md](./GAME-RULES.md) · [AGENTS.md](../AGENTS.md) · [ENGINEERING.md](./ENGINEERING.md)

第一关原型在 `src/game/`。这一关是三颗轻球、三条皮筋、三只蓝色口袋，上下各排成一行。每只口袋收一颗。错色、星、残影、音效还没做。口袋的做法以本文第 7 节为准。其余规则以 [GAME-RULES.md](./GAME-RULES.md) 为准。

## 2. 动画和结算

操作优先见 [GAME-RULES.md](./GAME-RULES.md) 第 0 节。代码里，只有 `settling`（进袋直到停稳）和心扣没后的 `gone` 不接受这颗球的拉。其余状态手都可以打断。结算不锁旁边还有球的皮筋。

| 段 | 状态 | 手指 |
|----|------|------|
| 动画 | `launching` 收回、`flying` 飞行、`catching` 回弹、`returning` 扣心后等放回托 | 托心周围约 90 像素可以打断。回弹时按的是球。球停在手指处，开始新的一拉。不扣心，不进袋 |
| 结算 | `settling` 进袋直到停稳并消失；最后一颗心之后的 `gone` | 这一颗拉动无效 |

飞行中按的是原来的托，不是天上的球。回弹中按的是球当时的位置。被别的皮筋接住时，打断之后球算那根皮筋的。

## 3. 坐标和时间

手指先经过舞台的包围盒换成设计坐标，忽略 letterbox 外面的点。玩法内部向右为正、向上为正。画到 Three.js 时不再翻一次。

相机正投影，固定盖住 390×844。镜头不跟球。

模拟每步 1/60 秒。从后台回来，一次最多补 0.25 秒。画面画最近一步的位置，不在两步之间插值。

Rapier 的 `lengthUnit` 是 80。不改的话，像素速度会被夹掉。

## 4. 三个数

下沉和松手速度只从劲度、质量、重力来，不另写一套。画面右上角的参数面板改的是这一局，不写回文件。默认值如下。

| 项 | 默认 | 单位 |
|----|------|------|
| 皮筋劲度 | 150 | 拉力 = 劲度 × 拉长 |
| 基础质量 | 1 | 最轻的球。更重的球是它的倍数 |
| 全局重力 | 3800 | 设计像素 / 秒² |
| 阻尼 | 0.30 | 接住和空皮筋收回时的衰减 |
| 口袋阻尼 | 0.60 | 外轮廓和进袋共用。面板可改 |
| 皮筋粗细 | 7 | 像素。满拉留下约七成 |
| 球半径 | 18 | 像素。相邻两根皮筋之间的空档大于球的直径 |

由此得到：

- 下沉 = 质量 × 重力 / 劲度。球的质量为 1 时约 25.3 像素。
- 空皮筋的质量是球的九分之一，下沉约 2.8 像素，所以没球时更紧。
- 松手速度 = 拉长 × √(劲度 / 球的质量)。方向指向没被拉开的托。手指速度不算。
- 死区 28 像素。短于死区就退回，不发射。
- 向下和两侧的最大拉动幅度，是托到地面上方停住的这段距离，现在是 158 像素。不能拉进地面。
- 向上时皮筋不停在拉直。它最高就是没球时的默认弧。球压到这条弧上之后，皮筋不再跟着升。
- 球还可以再向上 18 像素。再往上就脱手：从当时的位置只受重力下落，落回这条默认弧，再被接住坐回托。不按松手发射，不扣心。手指还按着也不算新的一拉，要先抬手。

## 5. 皮筋

两端各一颗铆钉，钉在托的斜上方。不是分叉弹弓。铆钉固定，半径 5，颜色跟皮筋一样。每根皮筋左右各伸出 32 像素。相邻两根皮筋的铆钉之间空出约 43 像素，大于球的直径 36，球可以从这道缝里掉下去。

- 铆钉挡住球。球心离铆钉中心不能近于两个半径之和。拉、收回、接住回弹都停在外面。
- 飞着的球碰上就弹开，沿法线留下大约四分之一的来速。地面几乎不弹。
- 同一根皮筋的两颗铆钉不夹球。球心落在这两颗之间时，它们让开，球照常往下掉，不会卡在上面。从两颗外侧撞来的球仍然被挡住。
- 铆钉不接球，不扣心，也不算落上皮筋。

- 球压在上面：两边各 4 段直线，贴着球底的弯分成 20 段，整根 29 个点。内缘贴住球，中间不留缝。空着的浅弧也用这 29 个点。
- 球离开后：整条是一条绷紧的浅弧，用空皮筋自己的下沉。收回时会略微冲过，再停住。
- 拉动：向下和两侧，两边贴直，托球的弧朝向这一下拉力，至少弯过球的一侧，不收成一个贴在球边上的尖角。两端之间向上抬时，弧留在球下，不翻过球顶。皮筋到达没球时的默认弧之后就停住。没拉时弧朝重力。接住回弹时弧跟着球慢慢转。
- 拉得越满，皮筋越细。满拉留下约七成粗细。不变色，球不变形。拉到最大幅度时，球和皮筋一起沿拉力方向轻抖，幅度 1.6 像素，两端不动。抖动不改变松手速度。

皮筋是一条带子，不许出尖，也不许在拐弯处裂开。

- 中心线先走两端的切线，中间贴着球。切线穿球、两边交叉，或弧要翻过半圈时，不用「再缩小直到变成一个点」。缩成一个点时，铆钉上的线会从球里穿出去，画面上就是一根尖。
- 这时每一侧各自找切点。铆钉在球外，就从铆钉连到这一侧的切点，这段线贴着球边停下，不准穿进球，也不准因为切线没配对就把整条带子藏起来。铆钉已经在球里，才不拉这一侧。两边的切点之间仍贴着球绕，不收到一个点上。
- 描边的圆角半径就是半个粗细。拐弯只补这块圆角。斜接会沿角平分线拉得很长，那也是尖，不用。折返回来的点丢掉，不参与描边。

松手之后：

1. 托点用皮筋自己的小质量收回，球还在托上。
2. 回到托时球脱离，速度用上面的公式，质量用球的质量。
3. 空皮筋留着收回的速度，整条弧弹回去。
4. 脱离之后球只受重力，直到进袋、被皮筋接住，或落地。

## 6. 接住

球还在向外飞的时候，自己的皮筋弹回扫过托，不算接住。要等球掉头之后再碰上自己的皮筋，才算接住。旁边已经射出的空皮筋，球碰上就接住，并改坐到那根托上。托上还有球的皮筋不接。

接住时球还带着碰上的速度。同一条劲度把它拉回托，幅度自己变小。晃动小到看不出来才停在托上。接住不扣心。

飞着的球砸到另一根皮筋上的球时，那颗球和它的皮筋按碰上的速度晃一下，再荡回托上。轻碰幅度小，撞得快就荡得远。这是回弹，手可以按住这颗球打断。托上没有球的皮筋不会因此凭空多出一颗。

落在皮筋外面、掉到地上或飞出画面，扣一颗心。心还在就放回托上。心没了，这一发结束。放回托的等待可以打断。最后一颗心扣没后的消失不能打断。

## 7. 口袋

这一关的目标是三只蓝色半透明口袋。左右两只在设计坐标 y = 268，中间一只在 y = 428。x 仍是 78、195、312。每只开口向上，轮廓是 U 形，没有另加的装饰边，只收一颗。球心先穿过哪只开着的袋口，那只就在这一帧封口。同一帧两颗都进，左边的口袋先算。面板里的「蓝色袋子」可以一起关掉。

下面三根皮筋用同一行的 x，托的 y 是 612。每根托上有一颗球。空托不能拉。

口袋和球在同一层。外轮廓挡球。两壁之间、袋口以上的那一列是空的，球心从这里落下才算进袋。

- 进袋：球心向下穿过袋口的那一帧封口。重力关掉，碰上的速度留下。劲度和口袋阻尼把球收到袋底。这是结算，播完之前不能拉。停进袋不扣心。球停稳后，这只口袋和里面的球一起消失，不再挡别的球。
- 外轮廓：只沿第一次碰上的法线往外推，最多陷进 22 像素。分开之后力消失，不把球吸回袋边。球仍受重力。
- 封口之后，袋口那条边也变成轮廓。

进袋和外轮廓用同一套劲度和口袋阻尼。进袋会把球留下，外轮廓只挡一下。这两处的结果不同，材料参数相同。
